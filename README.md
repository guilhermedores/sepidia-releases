# Sepidia — instaladores

Baixe a versão mais recente em [Releases](https://github.com/guilhermedores/sepidia-releases/releases/latest).

- **macOS Apple Silicon (M1/M2/M3…):** `Sepidia-<versão>-arm64.dmg`
- **macOS Intel:** `Sepidia-<versão>-x64.dmg`
- **Windows:** `Sepidia-Setup-<versão>-x64.exe`

Quem já tem o app recebe as atualizações sozinho. Este repositório guarda só os instaladores.
